🤖 AI Entity Safeguards & Lock Directives

These safeguard directives prevent the AI coding assistant from making unintended edits to critical database schemas, modals, and business logic. By default, all master entities are LOCKED until explicitly unlocked in your prompt.

🛡️ Master Entity Protection Matrix

Module / Entity Default Status Unlock Shortcut Single Entity Prompt (`#o`)
👤 Customer Master 🔒 Locked #unlock:customer #o customer
🏢 Vendor Master 🔒 Locked #unlock:vendor #o vendor
🚛 Transporter Master 🔒 Locked #unlock:transporter #o transporter
📦 Items & Fabric Types 🔒 Locked #unlock:items #o items
📝 Sales Orders (SO) 🔒 Locked #unlock:so #o so
🛒 Purchase Orders (PO) 🔒 Locked #unlock:po #o po
📦 Goods Receipt (GRN) 🔒 Locked #unlock:grn #o grn
🚚 Outward Challans 🔒 Locked #unlock:outward #o outward
🔄 Busy Sync Agent 🔒 Locked #sync #sync
💡 Example Usage in Chat Prompt:
• "Fix alignment issue in Customer table #o customer" (Edits Customer only; leaves Vendor untouched).
• "Modify GRN save function #unlock:grn" (Unlocks GRN module for editing).
• "Update UI layout #ui" (Frontend UI edits only; no backend DB payload changes).
